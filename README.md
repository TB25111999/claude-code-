# Meine To-dos

Persönliche To-do-App für iPhone, iPad und Browser.

- Aufgaben mit Titel, Notiz, Start- und Enddatum
- Kategorien: Trading, Techniker, Fitness, Arbeit, Privat, Finanzen, Lernen, Haushalt – plus eigene
- Prioritäten Hoch / Mittel / Niedrig
- Gruppiert nach Fälligkeit (überfällig, heute, läuft, nächste 7 Tage, später), mit Zeitfortschritt
- Filter, Suche, Sortierung; Hell- und Dunkelmodus
- Installierbar auf dem Home-Bildschirm, funktioniert offline
- Abgleich zwischen Geräten über Supabase (mit Login)

**Einrichtung:** siehe [ANLEITUNG.md](ANLEITUNG.md).

Ohne Supabase lässt sich die App auch nur lokal nutzen („Ohne Sync nur auf diesem Gerät nutzen“).
